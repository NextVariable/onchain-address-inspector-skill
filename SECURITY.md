# Security

安全报告 · Security policy

Report a vulnerability through the **Security → Report a vulnerability** page of this repository. Do not put credentials, personal data or exploit details in a public issue.

Include the affected commit, how you ran it, and the smallest reproduction you can make with synthetic data. Never include private keys or seed phrases. The tool is read-only and only needs public addresses.

This is a volunteer-maintained project. Reports are read and answered as time allows, with no fixed response time. Fixes land on `main`.
